

# 🎓 NAPHTECH HUB

A modern university student information system built for the Federal University of Applied Sciences, Kachia (FUASK).

## Current Features

- Student Registration
- Student Login
- Student Dashboard
- Logout
- Responsive Homepage
- Mobile Friendly
- Express.js Backend
- JSON Database

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Express Session
- bcryptjs
